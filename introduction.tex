\section{\textbf{Potential Vulnerabilities} }

\subsection{Categories of Security weaknesses}
\begin{enumerate}
    \item Physical
    \item Technology
    \item Policy
    \item Configuration
    \item Human
\end{enumerate}
\subsection{Physical}
Buildings and equipment rooms may be vulnerable

Intruders can break into server room , and sabotage it

Guards , Locks , Biometric devices must provides a protection against breaks in

\subsection{Technology}
Every technology has known or unknown inherent weaknesses or vulnerabilities.

Some of this issues is :
\begin{itemize}
    \item Internet protocols were not designed for security
    \item Computers and networks operating systems have vulnerabilities
    \item Network equipments (Routers - Switches - and more...) may be have vulnerabilities must be recognized and protected against
\end{itemize}
\subsection{Policy}
Security police weakness is catchall phrase of company policies or lack of polices
Some of issues that can negatively impact the policy :
\begin{itemize}
    \item No written security policy
    \item Lack of disaster recover plan
    \item Lack of security monitoring
    \item No Policy for hardware and software additions or changes
    \item Internal policies
    \item Employment policies
\end{itemize}
\subsection{Configuration}
Many network devices have default settings that ease of installation without regard for security issues.

Network administrators need reconfigure the computing devices.

\subsubsection{Some common configuration issues include}
\begin{itemize}
    \item User IDs and Passwords in clear text
    \item Old , missing , duplicate passwords
    \item Unauthorized or weak remote access through the internet.
\end{itemize}
\subsection{Human}
The people who administer and use the computer system represent the greatest vulnerability of all. 

Human stupidity, carelessness, laziness, greed, and anger represent the greatest threats to computer system security.
